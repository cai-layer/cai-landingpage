# Keyboard Shortcuts

Cai is designed to be used entirely from the keyboard.

## Global

| Shortcut | Action                                                          |
| -------- | --------------------------------------------------------------- |
| **⌥C**   | Trigger Cai (works anywhere on macOS, customizable in settings) |

## Action Window

| Shortcut      | Action                                             |
| ------------- | -------------------------------------------------- |
| **↑ ↓**       | Navigate between actions                           |
| **↵** (Enter) | Execute selected action                            |
| **⌘1–9**      | Jump directly to an action by number               |
| **⌘N**        | New chat (ask anything, without clipboard content) |
| **⌘0**        | Open clipboard history (searchable, with pinning)  |
| **⌘T**        | Open [Today](/docs/usage/today/)                   |
| **Esc**       | Go back / Dismiss the window                       |

## Today

| Shortcut | Action |
| -------- | ------ |
| **↵** or **⌘↵** | Copy the item's prompt and close Cai |
| **→** | Open the item's details (**←** goes back) |
| **⌘C** | Copy the prompt and keep Cai open |
| **⌘O** | Open the item's first link |
| **⌘D** | Mark done |
| **⌘⌫** | Dismiss |
| **⌘S** | Snooze until tomorrow, or unsnooze |
| **⌘Z** | Undo the last done, dismiss or snooze |
| **⌘R** | Refresh the list |

To open Cai straight on Today from any app, record a **Today Shortcut** in **Settings** → **Today**. See [Today](/docs/usage/today/#today-shortcut).

## Ask AI

| Shortcut | Action              |
| -------- | ------------------- |
| **⌘↵**   | Submit your question |
| **Esc**  | Back to action list |

## Result View

| Shortcut | Action                                         |
| -------- | ---------------------------------------------- |
| **↵**    | Copy result and exit                           |
| **⌘1**   | Replace your original selection with the result |
| **Tab**  | Ask a follow-up question on the result         |
| **← →**  | Page through kept results (when one is open)   |
| **Esc**  | Back to action list                            |

## Results

Click the pill in the action window header to see what runs, what waits, and your recent results.

| Shortcut | Action                          |
| -------- | ------------------------------- |
| **↑ ↓**  | Choose a result                 |
| **↵**    | Copy it and close               |
| **→**    | Open it in full                 |
| **Esc**  | Back to the list, then close    |

## Menu Bar

| Action                           | How                               |
| -------------------------------- | --------------------------------- |
| Open Settings                    | Left-click the Cai menu bar icon  |
| Pinned and recent clips, with search | Right-click the Cai menu bar icon |
| Open Today | **Today** in the right-click menu |
| Open Settings from the menu      | **Cai Settings…** (⌘,) in the right-click menu |
| Open Settings from action window | Click the Cai logo in the footer  |
| Start or stop Keep Awake         | Left-click the Cai logo, once [Keep Awake](/docs/usage/menu-bar-tools/) is enabled (it then replaces Open Settings) |
| Focus timer quick controls       | Left-click the countdown next to the logo ([Focus Timer](/docs/usage/menu-bar-tools/#quick-controls)) |
